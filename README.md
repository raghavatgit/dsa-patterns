# Data Structures & Algorithms Patterns Library

A curated repository of 85+ production-grade algorithmic problem solutions and architectural patterns implemented in C, C++, Rust, and Python.

## Core Problem Categories
- **Sliding Window & Two Pointer**: 3Sum, Container With Most Water, Longest Substring Without Repeating, Minimum Window Substring, Trapping Rain Water.
- **Monotonic Stack & Deque**: Sliding Window Maximum, Daily Temperatures, Next Greater Element, Largest Rectangle in Histogram, Maximal Rectangle.
- **Tree & Graph Algorithms**: Lowest Common Ancestor, Binary Tree Max Path Sum, Number of Islands, Clone Graph, Dijkstra, Bellman-Ford, Prim MST, Kahn Topological Sort.
- **Dynamic Programming**: Longest Increasing Subsequence (Patience Sorting), Edit Distance, Coin Change I & II, Word Break, House Robber I-III, Burst Balloons.
- **Trie & Backtracking**: Implement Trie, Add and Search Words, Word Search II, N-Queens.
- **Hard Binary Search**: Median of Two Sorted Arrays, Split Array Largest Sum.
