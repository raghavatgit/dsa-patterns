# Data Structures & Algorithms Patterns Library (Master Index)

A curated repository of 90+ production-grade algorithmic problem solutions and architectural patterns implemented in C, C++, Rust, and Python.

## Core Problem Categories
- **Linked Lists**: Swap Nodes in Pairs, Rotate List, Partition List, Reverse Linked List II, Reorder List, Sort List Merge Sort.
- **Binary Trees**: Level Order, Zigzag, Right Side View, Invert Tree, Subtree Check, Maximum Width, Distance K, Vertical Order, Lowest Common Ancestor.
- **Binary Search Trees**: Validate BST, Recover BST, LCA in BST.
- **Sliding Window & Two Pointer**: 3Sum, Container With Most Water, Longest Substring Without Repeating, Minimum Window Substring, Trapping Rain Water.
- **Monotonic Stack & Deque**: Sliding Window Maximum, Daily Temperatures, Next Greater Element, Largest Rectangle in Histogram, Maximal Rectangle.
- **Graph Algorithms**: Number of Islands, Clone Graph, Dijkstra, Bellman-Ford, Prim MST, Kahn Topological Sort.
- **Dynamic Programming**: LIS Patience Sorting, Edit Distance, Coin Change I & II, Word Break, House Robber I-III, Burst Balloons.
- **Hard Algorithms**: Median of Two Sorted Arrays, Longest Valid Parentheses, First Missing Positive, N-Queens Bitmask.
