# Pattern: Binary Tree Traversals

## Traversal Types
1. **Preorder (Root -> Left -> Right)**: Tree cloning, serialization, prefix expression evaluation.
2. **Inorder (Left -> Root -> Right)**: Binary Search Tree monotonic sorted sequence extraction.
3. **Postorder (Left -> Right -> Root)**: Bottom-up subtree calculations (height, subtree sum, deletion).
4. **Level-Order (BFS Queue)**: Shortest distance, top-down layer serialization.
5. **Morris Inorder Traversal**: $O(N)$ time and $O(1)$ space using threaded binary tree pointers without stack.
